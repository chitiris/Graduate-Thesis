# Pirate Parrot Radio: Διαδικτυακός ραδιοφωνικός σταθμός για Smartphone

**Ανάπτυξη εφαρμογής διαδικτυακού ραδιοφωνικού σταθμού για Smartphone βασισμένη στο cloud.**
Πτυχιακή εργασία, ΤΕΙ Δυτικής Μακεδονίας, 2016.

- **Επιβλέπων καθηγητής:** Α. Μιχάλας

## Περιγραφή

Η παρούσα πτυχιακή εργασία εκπονήθηκε με σκοπό την ανάπτυξη μίας λειτουργικής εφαρμογής για «έξυπνα» κινητά τηλέφωνα με λειτουργικό σύστημα κυρίως Android (δίνεται και η δυνατότητα για επέκταση για iOS και Windows phone) αλλά οι υπόλοιπες πλατφόρμες έχουν την δυνατότητα να συνδεθούν μέσω του responsive site με τον σταθμό. Η εν λόγω εφαρμογή παρέχει στους χρήστες τη δυνατότητα να ακούσουν ζωντανά τη μετάδοση του ραδιοφωνικού σταθμού που έχουν επιλέξει, ενώ ταυτόχρονα μπορούν να επικοινωνήσουν με τους άλλους χρήστες και τον παραγωγό που παίζει μουσική εκείνη την στιγμή.

Στα κεφάλαια που ακολουθούν επιχειρείται η προσέγγιση και κατανόηση του λειτουργικού συστήματος Android μέσω της ετυμολογίας της ονομασίας του, την ιστορία του, του τι είναι το Android, καθώς και η παρουσίαση των μέχρι σήμερα εκδόσεων που έχουν διατεθεί κατά περιόδους στους χρήστες και αναλύεται η αρχιτεκτονική της πλατφόρμας Android. Επίσης παρουσιάζεται μια ιστορική αναδρομή για το ραδιόφωνο και περιγράφονται οι βασικές υπηρεσίες του διαδικτυακού ραδιοφώνου.

Στα τελευταία δύο κεφάλαια παρουσιάζεται η λειτουργική εφαρμογή που πραγματοποιήθηκε στα πλαίσια της παρούσας πτυχιακής εργασίας. Αναφέρονται επιπλέον οι απαιτήσεις λειτουργίας της εφαρμογής καθώς και τα εργαλεία που απαιτήθηκαν για την ανάπτυξή της. Στην συνέχεια, ακολουθεί η περιγραφή χρήσης της εφαρμογής κατά περίπτωση, πραγματοποιείται η ανάλυση και σχεδίαση της εφαρμογής PPR Application με την χρήση διαγραμμάτων και αναφέρονται τα συμπεράσματα και οι προτάσεις για μελλοντική έρευνα με σκοπό την βελτιστοποίηση της εφαρμογής.

## Λειτουργίες της εφαρμογής

Η εφαρμογή (PPR – Pirate Parrot Radio) έχει τρεις καρτέλες:

| Καρτέλα | Τι κάνει |
|---|---|
| **Player** | Παίζει ζωντανά το stream του σταθμού και ανανεώνει κάθε 2 δευτερόλεπτα το τραγούδι που παίζει, το είδος μουσικής και τον αριθμό ακροατών. Όταν ο σταθμός δεν εκπέμπει, εμφανίζει οθόνη «offline». |
| **Chats** | Chatroom σε πραγματικό χρόνο: ο χρήστης δίνει ένα username και συνομιλεί με τους άλλους ακροατές και τον παραγωγό. Εμφανίζονται τα 5 τελευταία μηνύματα. |
| **About** | Στοιχεία της πτυχιακής εργασίας. |

## Αρχιτεκτονική

```
 ┌──────────────────────┐   audio stream + status JSON   ┌───────────────────────┐
 │  Εφαρμογή (myapp/)   │ ◄───────────────────────────── │  Icecast server       │
 │  Ionic + AngularJS   │                                │  (θύρα 8000)          │
 │  Cordova / Android   │   μηνύματα chat (Socket.IO)    ├───────────────────────┤
 │                      │ ◄────────────────────────────► │  Chat server          │
 └──────────────────────┘                                │  (chat server/, 3000) │
                                                         └───────────────────────┘
```

- **Streaming:** ο σταθμός εκπέμπει μέσω Icecast. Η εφαρμογή διαβάζει το `status-json.xsl` του Icecast για τα «Now Playing» στοιχεία.
- **Chat:** ένας μικρός server σε Node.js (Express + Socket.IO) αναμεταδίδει κάθε μήνυμα σε όλους τους συνδεδεμένους χρήστες.

## Τεχνολογίες

- **Mobile app:** Ionic Framework 1.3, AngularJS, Apache Cordova (Android, min SDK 16)
- **Chat server:** Node.js, Express 4, Socket.IO 1.4
- **Streaming:** Icecast
- **Build:** Gulp, Bower

## Εκτέλεση (ιστορική σημείωση)

Το project γράφτηκε το 2016 με εργαλεία που σήμερα είναι παρωχημένα (Ionic 1, Socket.IO 1.x, Gulp 3), οπότε δεν τρέχει «έτοιμο» σε σύγχρονο περιβάλλον. Οι διευθύνσεις του Icecast και του chat server είναι γραμμένες απευθείας στα `myapp/www/js/controllers.js` και `myapp/www/js/services.js` και αφορούσαν τον server της εποχής.

Ενδεικτικά, με Node.js της εποχής:

```bash
# Chat server
cd "chat server"
npm install
node index.js            # ακούει στη θύρα 3000

# Εφαρμογή
cd myapp
npm install -g cordova ionic@1
npm install
ionic serve              # προεπισκόπηση στον browser
ionic run android        # εγκατάσταση σε συσκευή Android
```
